# Casa Becerra Rodriguez

Proyecto de construcción de casa para nuestros padres.
**Interesados:** 7 hermanos (2 mujeres, 5 hombres)

## Sistema de organización

Nomenclatura **Johnny Decimal incremental**:

| Rango | Categoría | Propósito |
|-------|-----------|-----------|
| 10 | inbox | Entrada de documentos sin clasificar |
| 11 | stakeholders | Entrevistas y opiniones |
| 12 | acuerdos | Decisiones consensuadas |
| 13 | presupuesto | Control financiero |
| 21 | espacios | Requerimientos de espacios |
| 22 | acabados | Materiales y acabados |
| 31 | planos | Diseños arquitectónicos |
| 41 | cronograma | Seguimiento de obra |

## Nomenclatura de archivos

```
[categoria].[secuencia]-[descripcion].md
```

Ejemplo: `11.01-entrevista-juan.md`

## Reglas

1. **Sin archivos en raíz** (excepto README)
2. **Carpetas solo si son requeridas**
3. **Nombres semánticos en minúsculas**
4. **Flujo:** `10-inbox/` → Agente Bibliotecario → carpeta destino
